# AI Debate Arena Browser

这是一个纯浏览器本地版的多 AI 辩论/讨论应用，不依赖 Node.js 后端。

## 使用方式

直接打开 `index.html` 即可使用核心功能。

如果需要 PWA / Service Worker，请使用任意静态服务器打开本目录，因为浏览器通常不允许在 `file://` 页面注册 Service Worker。

## 功能

- 辩论模式：多个 AI 按轮次发言。
- 讨论模式：用户发言后，AI 同伴依次回应。
- 支持 OpenRouter、OpenAI Compatible、Google Gemini、Anthropic、Manual/Custom。
- 支持流式输出。
- 支持图片和文本附件。
- 支持只上传附件后发送。
- 支持模型发现和模型能力补全。
- 支持导出 Markdown 和 JSON。
- API Key 和 Provider 配置默认保存在本机浏览器 localStorage。

## 安全说明

API Key 会默认保存在当前浏览器的本地存储中，方便下次直接使用。请只在可信设备和可信浏览器配置中使用。

如果你不希望继续保存密钥，可以在浏览器开发者工具中清除 `localStorage`，或清除该站点数据。

## CORS 说明

这是纯浏览器应用，所有 API 请求都从浏览器直接发出。部分官方 API 或自定义网关可能不允许浏览器直连，表现为 `Failed to fetch`、403 或预检请求失败。

推荐优先使用：

- OpenRouter
- 明确支持 CORS 的 OpenAI 兼容网关
- 本地开启 CORS 的模型代理

如果某个 Provider 不能直连，应用会提示 CORS 或网络相关错误，你仍可以手动填写模型信息作为配置保存。

## 模型发现

模型信息使用混合策略：

1. 优先读取接口返回的模型列表。
2. 用内置模型表补充上下文长度、图片能力等信息。
3. 接口和内置表都没有的信息显示为未知。
4. 你可以在参与者编辑中手动填写上下文长度、最大输出 Tokens 和图片能力。

## 与旧版相比

- 不再启动后端服务。
- 不再监听局域网端口。
- 不再有后端全局状态串线问题。
- 不再使用 SSE 广播给所有客户端。
- 修复了 PWA 缓存不存在图标的问题。
- 允许只上传文件发送。
- 增加了导出能力和模型发现能力。
